# Contributing to SmartCity360

Thank you for contributing to SmartCity360. We maintain strict standards for municipal software excellence, code quality, and zero-fake metrics.

## Code Standards
1. **Python**: Black formatter, Ruff linter, strict type hints with Mypy.
2. **TypeScript**: ESLint, Prettier, strict TypeScript (`strict: true`).
3. **Commit Messages**: Conventional Commits specification.
4. **Pull Requests**: Include full PR metadata and test verifications.
5. **Zero Fabrication**: Never forge metrics, LOC, or synthetic benchmarks. Run `python scripts/project_audit.py` before submitting work.
